# Figures

Figures for the manuscript, generated by the scripts in `src/figures/`.
Every panel is plotted from the files in `results/`, so the figures can be
regenerated in step with the numbers they report:

    python src/figures/make_pipeline_figure_v2.py # Figure 1
    python src/figures/make_architecture_v2.py    # Figure 2
    python src/figures/make_results_figures.py    # Figures 3-7

The figure scripts use final print dimensions (6.5 inches wide), 8-point body
text, and 400 dpi PNG output. Insert the PNGs at native size without scaling.

## Reviewer-requested supplementary analyses

Export one CSV containing `y`, `p_symptom`, `p_pulmonary`, `p_fused`,
`p_pooled`, the 14 symptom columns, and the optional `threshold`,
`SDMVSTRA`, `SDMVPSU`, and `WTMEC2YR` columns, then run:

    python src/experiments/supplementary_analyses.py --input exported.csv

For three pooled NHANES cycles, the survey analysis divides `WTMEC2YR` by
three before the design bootstrap.

The manuscript text is not kept in this repository.
